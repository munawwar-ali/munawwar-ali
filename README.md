<details>
<summary><b>RankForge Engine</b> &nbsp;·&nbsp; Node.js · Redis · MongoDB · Docker · TypeScript</summary>

<br>

A high-performance leaderboard and ranking engine built to explore the intersection of in-memory data structures and persistent storage — designed for scale from the ground up.

| Attribute | Details |
|---|---|
| **Stack** | Node.js · Redis · MongoDB · Docker · TypeScript |
| **Performance** | O(log N) complexity for score updates and rank queries |
| **Data Layer** | Redis Sorted Sets for ranking · MongoDB for durable persistence |
| **Infrastructure** | Fully containerised via Docker · Multi-service orchestration |
| **Design Pattern** | Clean separation of speed (Redis) and durability (MongoDB) |
| **Repository** | [github.com/munawwar-ali/RankForge-Engine](https://github.com/munawwar-ali/RankForge-Engine) |

Purpose-built to explore Redis Sorted Sets as a ranking primitive at scale. The system separates the real-time ranking concern (Redis) from the persistence concern (MongoDB), containerises all services with Docker, and provides a clean TypeScript interface for score ingestion and leaderboard queries.

</details>
